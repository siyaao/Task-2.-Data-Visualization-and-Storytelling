Data Visualization and Storytelling using Power BI

Project Overview

This project focuses on creating an interactive dashboard using Power BI to analyze sales data from the Superstore dataset. The objective is to transform raw sales data into meaningful visualizations and business insights that support decision-making.

Objective

- Create effective visualizations using Power BI.
- Present business insights through data storytelling.
- Identify sales trends, regional performance, product performance, and profitability.
- Develop an interactive dashboard with filters and KPI indicators.

Dataset

Dataset Used: Superstore Sales Dataset

The dataset contains information related to:

- Orders
- Sales
- Profit
- Product Categories
- Customer Segments
- Regions
- Order Dates

Tools Used

- Microsoft Power BI
- Microsoft Excel (for data review and preparation)

Dashboard Components

KPI Cards

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Sales per Order

Visualizations

- Sales Performance by Category
- Profit Analysis by Category
- Sales Trend Over Time
- Regional Sales Comparison
- Top Products by Sales
- Customer Segment Analysis

Interactive Filters

- Region
- Category
- Year

Key Insights

- Technology is one of the strongest-performing product categories.
- Sales demonstrate an overall positive trend over time.
- Regional performance varies across different markets.
- A small number of products contribute significantly to total sales.
- Customer segments show different purchasing behaviors and revenue contributions.

Project Deliverables

- Power BI Dashboard (.pbix)
- Dashboard Screenshots
- Summary Report
- Dataset

Outcome

This project demonstrates the use of data visualization and storytelling techniques to convert business data into actionable insights. The dashboard enables users to explore sales performance, identify trends, and support data-driven decision-making.
